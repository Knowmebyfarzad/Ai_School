# سایت دوره آموزشی — نسخه بتا ساده (MVP)

این یک نسخه به حداقل حد از سایت فروش دوره ویدیویی است.
معماری: **Next.js + PostgreSQL + Stripe + ویدیو محافظت‌شده (signed URL)**

## فایل‌های مهم

| مسیر | توضیح |
|------|-------|
| `prisma/schema.prisma` | مدل‌های دیتابیس: کاربر، دوره، ویدیو، سفارش، ثبت‌نام |
| `app/page.tsx` | صفحه اصلی |
| `app/login/page.tsx` | صفحه ورود (به سادگی با ایمیل) |
| `app/dashboard/page.tsx` | داشبورد کاربر و لیست دوره‌های خریداری شده |
| `app/video/[id]/page.tsx` | صفحه پخش ویدیو با بررسی دسترسی |
| `app/api/auth/login/route.ts` | ایجاد سشن کاربر |
| `app/api/stripe-checkout/route.ts` | ایجاد س션 پرداخت استریپ |
| `app/api/stripe-webhook/route.ts` | Webbhook استریپ:เมื่อ پرداخت انجام شد، سفارش و ثبت‌نام ثبت می‌شود |
| `app/api/video-signed-url/route.ts` | ساخت لینک موقت برای ویدیو |
| `app/api/stream/[videoId]/route.ts` | ارسال فایل ویدیو فقط اگر توکن معتبر باشد |
| `lib/auth.ts` | احراز هویت ساده با JWT در کوکی |
| `lib/stripe.ts` | تنظیم کلاینت استریپ |
| `lib/prisma.ts` | اتصال به دیتابیس |
| `docker-compose.yml` | اجرای دیتابیس و اپ با داکر |
| `nginx.conf` | پیکربندی نینکس برای VPS |
| `middleware.ts` | محافظت از مسیرهای `/dashboard` و `/video` |

## چطور کار می‌کند ( جریان کار )

1. **ورود:** کاربر ایمیل می‌زند → سشن JWT در کوکی ذخیره می‌شود.
2. **انتخاب دوره:** کاربر در داشبورد یا صفحه اصلی یک دوره را انتخاب می‌کند.
3. **پرداخت:** کاربر به Stripe Checkout رDIRکت می‌شود.
4. **تایید پرداخت:** استریپ وب‌هوک می‌فرستد → سفارش به `paid` تغییر می‌کند و کاربر در جدول `Enrollment` ثبت می‌شود.
5. **پخش ویدیو:** کاربر روی ویدیو کلیک می‌کند → سرور چک می‌کند که ثبت‌نام وجود داشته باشد → یک لینک موقت (signed URL) معتبر ۱ ساعت می‌سازد و ویدیو پخش می‌شود.

## اجرا در توسعه (لokal)

```bash
# ۱. نصب بسته‌ها
npm install

# ۲. فایل environs
cp .env.example .env
# بعد .env را باز کنید و مقادیر را تغییر دهید (استریپ تست و غیره)

# ۳. ایجاد جداول در دیتابیس Locally
# اگر پستگرس روی کارتان نصب است:
npx prisma db push

# ۴. اجرا
npm run dev
```

## اجرا روی VPS (داکر)

1. کد را روی VPS کلون کنید.
2. فایل `.env` را با مقادیر واقعی بسازید (スティچ لایو، دامنه، رمزهای قوی).
3. اجرا:

```bash
docker compose up -d --build
docker compose exec app npx prisma db push
```

4. نینکس را پیکربندی کنید و SSL را با Let's Encrypt فعال کنید.
5. وب‌هوک استریپ را در داشبورد استریپ به آدرس زیر می‌پوشانید:
   `https://doman-shoma.com/api/stripe-webhook`

## امنیت (نسخه بتا)

- کوکی `httpOnly` برای سشن
- لینک ویدیو منقضی‌سنج (۱ ساعت)
- بررسی ثبت‌نام قبل از ارسال فایل ویدیو
- تایید امضای وب‌هوک استریپ
- فقط مسیرهای مجاز در نینکس باز هستند

## چیزهایی که بعداً باید اضافه کنید

- رمز عبور به صورت هش شده (`bcrypt`)
- آپلود ویدیو به ذخیره‌سازی ابری (S3/MinIO) به جای فایل محلی
- استریم HLS به جای MP4 مستقیم (برای جستجوی سریع‌تر در ویدیو)
- DRM (Widevine / FairPlay) اگر محتوای بسیار حساس است
- Rate limiting برای صفحات ورود و پرداخت
- بکاپ روزانه دیتابیس

## نکته مهم برای شما

اگر پیش از این استراتژی انتشار و مستقر کردن را نداشته‌اید، این نسخه بتا بهترین راه برای یادگیری است. ابتدا روی localhost اجرا کنید، بعد یک VPS ارزان بگیرید و مراحل بالا را انجام دهید. هر خطایی که گرفتید، لاگ داکر را ببینید:

```bash
docker compose logs app
```
